Sistema de contratações e abertura de vagas do RH

Desenvolvimento Full Stack

A abertura de vagas dependia de aprovações espalhadas entre gestores e RH. O sistema leva cada requisição do rascunho à validação final, seguindo a hierarquia da empresa: aprovação em sequência, devolução, reenvio, reprovação e cancelamento, com histórico, notificações, controle de acesso por perfil, substituição auditada de aprovadores e integração com os dados organizacionais. 1.646 de 1.649 verificações aprovadas no relatório de QA e 637 testes de regressão aprovados.

PHP · Laravel · React · TypeScript · MySQL · PHPUnit

Provisionamento automatizado do servidor do ERP

Automação de ERP

Preparar o servidor do ERP exigia instalações manuais em sequência e várias reinicializações. A automação organiza o processo em 8 etapas verificáveis e repetíveis, com estado persistido, logs, retomada após cada reinicialização e interrupção na primeira falha. Uma rotina complementar em Python registra o ERP e ajusta as configurações do ambiente de testes depois da restauração do banco.

PowerShell · Python · Oracle · Windows Server

Integrações por API com autenticação OAuth 2.0

APIs e integrações

Sistemas internos precisavam trocar dados sem acesso direto ao banco. As integrações passam por uma plataforma de APIs, com autenticação e renovação de tokens: um coletor em PowerShell envia o inventário e o estado de cada máquina para o sistema de ativos de TI, e uma API cria usuários no ERP por procedures que validam a entrada, bloqueiam duplicidade e desfazem tudo em caso de erro. Fluxos testados com dados reais e com chamadas simultâneas.

APIs REST · OAuth 2.0 · PowerShell · PL/SQL · MySQL

Processamento automático de documentos recebidos por e-mail

Automação corporativa

Documentos em PDF chegavam por e-mail e dependiam de tratamento manual. A rotina em Python lê a caixa corporativa, identifica os anexos e registra tudo em banco de dados, com controle de duplicidade, tratamento de falhas, notificações e retenção de arquivos. Foi projetada para substituir um fluxo anterior em Power Automate. O modo de simulação mapeou 7.715 mensagens sem alterar nada na caixa; 92 testes automatizados.

Python · Microsoft Graph · SQL Server · OAuth 2.0
