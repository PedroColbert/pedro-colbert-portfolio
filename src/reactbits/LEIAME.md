# Componentes do React Bits

Copiados de https://reactbits.dev (registro oficial, variante TS-CSS) em 15/11/2026, sem alterações.
São de código aberto (licença MIT + Commons Clause). Quem monta cada um na página é `src/islands.tsx`.

| Componente | Onde aparece |
|---|---|
| DotGrid | Fundo do hero |
| CrystalizedBall | Bola de cristal ao lado do nome (usa a biblioteca `ogl`) |
| CursorGrid | Fundo da seção Perfil |
| Cubes | Fundo da seção Experiência inteira (só em telas maiores) |
| LogoLoop | Laço de tecnologias, em Competências (ícones do pacote `react-icons`) |
| TargetCursor | Mira nas seções Competências, Projetos e Contato (só com mouse) |
| SplashCursor | Rastro de tinta no site todo, atrás do conteúdo (só com mouse) |
| ClickSpark | Faíscas a cada toque (só em telas de toque) |
| StickerPeel | Adesivo que fica no ponto da página onde for solto (só com mouse) |
| LetterGlitch | Tela do terminal, em Bastidores |
| Threads | Fundo do Contato |

Para buscar outro: `https://reactbits.dev/r/<Nome>-TS-CSS.json`. Ler o código antes de usar.
